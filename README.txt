WALTRIX v2 — Smart Blockchain Radar

This prototype adds read-only TRON scanning:
- TRX native balance
- USDT TRC-20 balance (contract: TXLAQ63Xg1NAzckPwKHvzw7CSEmLMEqcdj)
- Up to 10 confirmed recent USDT TRC-20 transfers
- Tronscan links

Run: open index.html in a modern browser. For best results serve over HTTPS or localhost.
Data provider: public TronGrid API. Public API limits/CORS/availability may change; production deployment should use a backend proxy, caching, rate limiting, monitoring, and provider credentials kept server-side.
No private keys, seed phrases, signing, or transfers are used.
Not production-ready: no auth, database, alerts, subscriptions, payments, or hosting.
